# Smart Zoom Launcher

A simple, lightweight Python automation script that launches your specific Zoom class link instantly.

## How to Setup

1. **Download the Script:** Download `zoom_launcher.py` from this page and put it in a new folder on your laptop.
2. **Create a Link File:** In that exact same folder, right-click -> **New** -> **Text Document**. Name the file exactly `config.txt`.
3. **Paste Your Link:** Open `config.txt`, paste your personal Zoom class URL inside, and save it.
4. **Run:** Double-click `zoom_launcher.py` to instantly launch your class!

*Note: Make sure Python is installed on your computer.*
